# Hugging Face: датасет переписанных карточек

Здесь лежит рецепт публикации обезличенного датасета на Hugging Face Hub.

| Что | Куда | Из чего собирается |
| --- | --- | --- |
| **Dataset** | `product-card-rewrites` | `hf/data/rewrites.jsonl` — ввод (факты товара) → вывод (описание, summary, SEO-теги) |

## Зачем это нужно

GitHub отвечает на вопрос «как это сделано» — здесь лежат промпт, пайплайн и
правила. Hugging Face отвечает на вопрос «чем этим можно воспользоваться»: датасет
можно скачать, посмотреть в браузере и использовать как SFT-данные или как
few-shot примеры для русскоязычного e-commerce.

## Что публикуется и что нет

**Публикуется:** синтетические и полностью обезличенные примеры — вымышленные
названия, артикулы, характеристики. Ни одной строки из реального каталога клиента
(728 карточек, бэкапы которых лежат в рабочей папке проекта) в датасет не попадает.

**Не публикуется:** боевые описания товаров, домены, бренды, цены — это данные
клиента, они остаются локально.

## Как собрать

Промпт и few-shot примеры берутся из самого репозитория (`prompts/`), так что
датасет воспроизводим и всегда соответствует текущей версии правил.

```bash
python hf/build_dataset.py --backend deepseek            # облако, лучшее качество
python hf/build_dataset.py --backend ollama              # локально, без интернета
python hf/build_dataset.py --backend ollama --ollama-model qwen2.5:7b
python hf/build_dataset.py --limit 6 --start 0           # только первые шесть
```

Ключи подхватываются из `../.env` рабочей папки проекта (`LLM_API_KEY` для
DeepSeek, `OLLAMA_BASE_URL` / `OLLAMA_WRITER_MODEL` для локального режима) или из
переменных окружения.

Скрипт валидирует каждый ответ модели: обязательны секция «Основные
характеристики», блоки `faq-item`, `summary_text`. Ответы с битым JSON
перезапрашиваются (до трёх попыток), для Ollama включён жёсткий режим
`format: json`.

Файл `hf/data/rewrites.jsonl` в git не попадает (`data/` в `.gitignore`).

## Как опубликовать

Нужен write-токен Hugging Face: `Settings → Access Tokens → New token → Write`.

```bash
export HF_TOKEN=hf_...        # Windows: set HF_TOKEN=hf_...
python hf/upload.py
```

Скрипт создаёт/обновляет датасет под вашим аккаунтом и заливает `rewrites.jsonl`
вместе с карточкой `hf/dataset/README.md`. Аккаунт берётся из токена.

## Ограничения

- Разметка сгенерирована моделью по промпту, а не выверена человеком.
- Локальные модели на слабой видеокарте пишут одну карточку минутами: 24 примера
  на `qwen2.5:14b` — это часы, поэтому для полного набора удобнее DeepSeek.
- Ниша в примерах иллюстративная (ткани, электроника, мебель); боевой прогон
  проверялся на каталоге текстиля.
